# @local/dsh-memo — 备忘 · 需求列表

**每个会话一份**的悬浮备忘面板，收起后变成右上角工具行里的小图标。用来记录“以后再做”的需求，
并让 AI 把你在对话里提到、但暂时搁置的需求挂到同一份列表上。

## 用起来是什么样

- **右上角图标**：会话头部右侧工具行里的小图标。有还没看过的新内容时右上角有一个小圆点
  （按主题的青绿强调色），打开面板看过就消失，和条目是否完成无关；AI 新增条目时会脉冲一次。
  点一下展开，再点一下收起。第一次安装默认展开一次，之后记住开关状态。
- **可移动 / 可缩放**：拖动标题栏移动，拖四边或四角都能调整宽高；双击标题栏复位到默认位置。
  位置和尺寸按浏览器记住，下一次打开还是你摆的样子。
- **悬浮面板**：从右侧平滑滑入 / 滑出，半透明底 + 毛玻璃 + 分层阴影；面板自带收起按钮，
  焦点在面板内时 Esc 也能收起并把焦点还给右上角图标。
- **需求列表**：单独滚动。需求名 + 详细信息；左侧圆圈勾选完成，已完成条目沉到底部、
  加删除线，可一键清除；点标题或详情就地展开。
- **添加 / 编辑抽屉**：面板底部常驻「＋ 添加需求」按钮，点开从底部滑出抽屉；标题栏的「+」
  是同一个入口。填需求名和可选的详细信息；点条目的铅笔（或标题）也用同一个抽屉编辑。
  抽屉带独立阴影，点遮罩或 Esc 关闭。
- **设置窗口**：标题栏齿轮按钮召唤一个**横向**的独立设置窗（左侧导航 + 右侧卡片，可拖动），
  每组设置是一张带阴影的卡片：
  - **文本文案**：按分组列出所有界面文字（可搜索），逐条改成你想要的措辞；留空即恢复默认，
    也可以「全部恢复默认」。`{n}` 这类占位符保留即可。
  - **外观**：弹窗背景（跟随主题 / 纯色 / 渐变 / 图片）、文字大小（11–17px，同时作用于
    备忘面板和设置窗口）、界面语言（跟随系统 / 中文 / English）。图片支持**上传本机文件**
    （PNG / JPEG / WebP / GIF，≤5MB），保存到 DSH 数据目录、由插件自己的路由提供，
    不经过外网；另有遮罩强度与背景模糊、实时预览。
  设置保存在 Host 侧，所有会话、所有页面共用，保存后立即生效。
- **AI 标记**：AI 挂起的条目带 `AI` 角标，副标题显示「进行中 N · AI 挂起 M」。

## 每个会话各自一份

列表按会话隔离：切换对话就切换列表，徽标、面板、AI 工具都只作用于当前会话。
AI 工具通过调用它的 Agent 所在会话定位列表，不会串到别的对话。

## 给 AI 用的工具

插件注册了一个全局工具 `memo`，作用域是“调用它的那个会话”：

| action | 参数 | 作用 |
|---|---|---|
| `list` | — | 读当前会话的列表 |
| `add` | `title`、可选 `detail` | 在当前会话新增一条，来源标记为 AI |
| `update` | `id`，加上 `title` / `detail` / `status` | 修改名称、详情或完成状态 |
| `remove` | `id` | 删除一条 |

另外插件会往系统提示词里加一小节，告诉每个会话的 AI：用户说“先记下来 / 以后再说”时
主动挂到备忘列表，用户问“还有什么没做”时用 `memo list` 读，而不是凭记忆回答。

## 数据放在哪

`.dsh-memo/memos.json`：优先 `<profile>` 目录，没有 profile 时用 `$DSH_HOME`（本机是 `~/.dsh`）。
文件按会话分组，并带一份全局设置
（`{ version: 3, sessions: { <sessionId>: { items: [...] } }, settings: { texts, background } }`）；
写入先落临时文件再原子替换，JSON 损坏时退回空状态而不是让插件加载失败。
旧的全局列表（version 1）会在第一次有会话读列表时整体迁移到该会话。

每个会话最多 200 条；需求名 200 字、详细信息 4000 字上限；最多保留 100 个有内容的会话。
文案覆盖最多 120 条、每条约 400 字；背景图片最大 5MB，存为 `.dsh-memo/background.*`。
数据不离开本机；图片由插件自己的同源路由提供。

## 限制

- 面板只存在于 Web GUI，不支持无浏览器的 headless 会话。
- 面板通过同源接口轮询（4 秒一次，切回窗口时立即刷新）与 AI 写入同步，
  不是 WebSocket 推送，因此 AI 刚写入的条目最多延迟几秒出现。
- 面板位置和尺寸保存在浏览器本地，不同浏览器 / 不同机器各记各的。
