# 变更记录

## 1.2.0 — 2026-11-28

### 新增

- **太空侵略者**：移植 [vrk/space-invaders](https://github.com/vrk/space-invaders)（MIT）。13 个浏览器脚本内联成一个工厂，改容器输入、App 接管 canvas、加 `pause/resume/destroy`、文案本地化；无图片/音频依赖。
- **推箱子**：移植 [taniarascia/sokoban](https://github.com/taniarascia/sokoban)（MIT）。ES modules 内联，canvas 进容器，容器键盘 + 重开按钮 + 胜利提示。
- **`docs/SECURITY-REVIEW.md`**：第三方源码「先审后下」的规则、检查项和本次记录；三个已移植仓库均通过网络/动态执行/存储/资产审查。
- `THIRD_PARTY_NOTICES.md` 增加太空侵略者、推箱子的 MIT 全文。

### 变更

- 第三方移植覆盖 canvas 单文件、canvas 多文件、ES modules 三种形态；游戏总数到六个。
- 版本 1.2.0；测试覆盖 `invaders`、`sokoban` 和审查文档。

## 1.1.0 — 2026-11-28

### 新增

- **乒乓球（pong）**：移植 [vruntime-labs/ping-pong](https://github.com/vruntime-labs/ping-pong)（MIT），第一个真实第三方 canvas 游戏。保留原游戏规则，改了容器化输入、固定 60Hz 步长、响应式画布、暂停/重开/先得 5 分，删掉外链和触屏按钮。
- **`THIRD_PARTY_NOTICES.md`**：保留上游 MIT 全文和改动说明。
- `docs/PORTING.md` 增加这次移植的实际改动表。

### 变更

- **开窗不再丢内嵌进度**：内嵌运行时保持挂载，开窗时暂停，收回后继续原来那局；窗口本身仍是独立一局。
- **主题热更新**：宿主监听 `theme/change`，通过 `host.theme.subscribe` 通知游戏；贪吃蛇和打砖块会更新调色板，不需重开。
- 兼容记分卡：B7 转 ✅、B13 转 🟡，汇总为 15 ✅ / 6 🟡 / 9 ❌ / 1 ⛔。
- 测试覆盖 pong 和第三方声明文件。

## 0.7.0 — 2026-11-27

### 变更

- **入口换位置**：从 `sidebar.panellist` 移到 `conversation.header.leading`（会话标题栏左侧的全局导航位）和 `sidebar.footer.action`（侧边栏底部 Settings 旁），两处都不受宿主侧边栏面板条目灰色底块的约束；改用 `layout.selectPanel('games')` 打开游戏页。
- 侧边栏不再注册游戏条目，避免出现「灰底 + 图标 + 文字」的方块。

### 新增

- **第三个游戏「2048」**：DOM 形态，验证 `native` 适配器可以承载「自己建 DOM + 自己管样式」的游戏，而不只是 canvas。
- **`docs/PORTING.md`**：移植现有 HTML5 小游戏的流程、2048 案例、限制与验收清单。

## 0.6.0 — 2026-11-27

### 新增

- **`web` 适配器**：`createWebRuntime` 把「只认 canvas 的普通 HTML5 游戏」提升到统一的运行时契约（`start / resize / pause / resume / destroy`）。
- **第二个游戏「打砖块」**：走 `web` 适配器接入，验证适配器链路；鼠标 / 左右键控制挡板、空格暂停、R 重开、生命与最高分。
- 游戏列表改为按 `GAMES` 渲染，卡片刻度支持多游戏。
- 「接入方式」区更新：原生与 HTML5 标为已跑通，Flash / SWF 标为待接入。

### 变更

- 侧边栏入口换成带渐变的方形徽标（`GameBadge`），会话标题栏按钮同步使用，替代原来的裸线条图标。

## 0.5.0 — 2026-11-27

### 新增

- **运行时契约落地**：`GameRuntimeView` + `createHost` 负责 `mount / resize / pause / resume / destroy`；ResizeObserver 处理尺寸、`visibilitychange` 处理切后台暂停、异常隔离与重试；host 提供 `theme / locale / save / log / exit`。
- **第一个原生游戏「贪吃蛇」**：Canvas 渲染、22×16 网格、方向键 / WASD / 滑动、空格暂停、R 重开、最高分按游戏持久化。
- 内嵌舞台与每个窗口共用同一个运行时组件，互不共享状态。

### 变更

- 移除演示画布，游戏列表改为真实游戏；卡片、抽屉、窗口标题都显示当前游戏。
- 打开窗口时内嵌实例会收起（不迁移进度），全部收回后重新开局。

## 0.4.0 — 2026-11-27

### 新增

- **自定义背景**：支持图片 / 视频，存在 IndexedDB（上限 60MB），铺满页面并加主题色遮罩；可一键恢复默认极光。重启后仍在。
- **内嵌舞台放大**：游戏视图隐藏副标题、收窄头部，舞台高度撑到视口高度减头部，抽屉加宽到 232px。
- **动效**：进入游戏时内嵌舞台从右侧滑入；窗口收回 / 关闭时向右淡出，舞台内容淡入。

### 变更

- 页面背景层抽象为 `BackgroundLayer`：有自定义背景时替换极光，没有时保持默认。

## 0.3.0 — 2026-11-27

### 新增

- **多窗口**：可同时打开多个应用内游戏窗口，各自独立的位置、尺寸、吸附模式，点击置顶；连续打开自动级联错位。
- **独立窗口接入位**：`apply` 探测 `ctx.get('desktopWindows')`，存在 `openPanel` 时调用开独立系统窗口；宿主未提供时回退成应用内窗口并提示。舞台「⋯」菜单新增「独立窗口（新开）」。
- 页面新增提示条（notice），用于说明回退等状态。

### 变更

- 关闭语义调整：窗口 × 只关该窗口；「全部收回内嵌」关掉全部；「关闭游戏」回首页。
- 窗口菜单精简为四种吸附模式 + 关闭，避免小窗口里菜单被裁切。

### 文档

- `WINDOW.md` 增加多窗口与独立窗口接入位说明。
- `DETACH.md` 记录宿主 API 提案与插件侧接入点。

## 0.2.1 — 2026-11-27

### 修复

- 深色主题下主按钮变成「白底白字」：DSH 深色主题的 `--dsw-alias-brand-primary` 是白色，而按钮文字也写死 `#fff`。改用 `var(--dsw-alias-bg-base)` 作前景色（深色主题深字、浅色主题白字），卡片缩略图和抽屉图标改用成功/警告色，不再用品牌色做浅色底。
- 极光背景在深色主题下偏灰：改用成功/警告色做彩色光斑，品牌色只留很低比例的高光。

### 文档

- 新增 `docs/DETACH.md`：自由窗（独立系统窗口）的宿主需求与插件接入方案。
- `WINDOW.md` / `ROADMAP.md` 补充 `window.open` 被拒的核查结果。

## 0.2.0 — 2026-11-27

### 新增

- 内嵌模式（默认）：游戏在游戏中心页面里，左侧抽屉选游戏，右侧舞台。
- 悬浮模式：双击舞台标题栏或「⋯ → 悬浮窗」进入；浮窗从右侧滑入，可拖拽、八向缩放、吸附左右半屏/全屏。
- 浮窗与内嵌互转：双击浮窗标题栏或点「内嵌」回到页面。
- 视觉：极光渐变背景、卡片/按钮阴影、悬停位移、入场动画、玻璃抽屉。
- 文档：`docs/` 全量建立（兼容性、运行时、窗口、UI、路线图、变更）。

### 修复

- 拖拽游戏窗口会带动整个 DSH 窗口：给页面和浮窗加 `-webkit-app-region: no-drag`（待实机确认）。
- 尺寸输入框打字时被最小值强行改写：改为失焦/回车提交。

### 已知限制

- 窗口无法拖出 DSH（宿主限制，见 `docs/WINDOW.md` 第 5 节）。
- 半屏是覆盖式，不是布局重排。
- 仍是框架预览，只有演示画布，没有游戏。
