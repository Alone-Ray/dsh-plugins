# 视觉与交互规范

> 状态：**基础视觉已实现**（阴影、渐变、滑入、动效）；自定义背景与视频背景为规划项。

## 1. 原则

- 颜色服从 DSH 主题：文字、边框、面板底色一律用 `--dsw-alias-*`，深色/浅色自动跟随。
- 有质感但不喧宾夺主：阴影只用于「浮起来的层」，平铺卡片用很轻的投影。
- 动效服务于状态变化：进入、切换、悬停，不做无意义循环动画（背景极光除外，且可被系统「减少动态效果」关掉）。

## 2. 颜色

| 用途 | 取值 |
|:--|:--|
| 文字 | `--dsw-alias-label-primary` / `--dsw-alias-label-secondary` |
| 背景 | `--dsw-alias-bg-base` / `-layer-1` / `-layer-2` / `-overlay` |
| 边框 | `--dsw-alias-border-l1` / `-l2` |
| 主强调 | `--dsw-alias-brand-primary` |
| 辅助色 | `--dsw-alias-state-success-primary`、`-warn-`、`-error-`，只做低透明度氛围，不做大面积色块 |

多彩感来自**低透明度渐变叠加**（极光背景、卡片顶部细高光、主按钮渐变），不新增硬编码的品牌色。

> 坑（0.2.1 修过）：深色主题下 `--dsw-alias-brand-primary` 是白色，不能拿它当填充色再配白字。主按钮的前景色用 `--dsw-alias-bg-base`（深色主题深字、浅色主题白字）；卡片的彩色底用成功/警告色，不要用品牌色。

## 3. 阴影与圆角

| 层级 | 用法 | 阴影 |
|:--|:--|:--|
| 0 | 平铺卡片 | `0 1px 2px rgba(0,0,0,.06)` |
| 1 | 悬停卡片、抽屉 | `0 10px 30px rgba(0,0,0,.12)` |
| 2 | 悬浮窗 | `0 24px 80px rgba(0,0,0,.32), 0 2px 8px rgba(0,0,0,.18)` |
| 3 | 菜单 | `0 12px 32px rgba(0,0,0,.22)` |

圆角：卡片 14px，按钮 10px，窗口 16px，抽屉 16px。

## 4. 动效

| 场景 | 时长 / 曲线 |
|:--|:--|
| 悬停、按下 | 140ms ease-out，位移 ≤2px |
| 窗口滑入 | 240ms `cubic-bezier(.22,.61,.36,1)`，从右侧 28px + 轻微缩放 |
| 内嵌舞台入场 | 300ms，从右侧 32px 滑入（打开游戏时） |
| 窗口收回 / 关窗 | 180ms，向右淡出 + 轻微缩小；舞台内容 220ms 淡入 |
| 抽屉展开 | 200ms，宽度过渡 |
| 卡片入场 | 300ms，逐张 40ms 延迟 |
| 背景极光 | 18s 往返缓慢漂移，透明度很低 |

`prefers-reduced-motion: reduce` 时全部关闭。

## 5. 组件清单

- 按钮：主按钮（渐变 + 光晕）、次按钮（描边）、幽灵按钮（纯文字）
- 卡片：游戏卡（缩略图 + 标题 + 描述 + 两个动作）、占位卡（虚线）
- 抽屉：游戏列表、当前项高亮、图标
- 舞台：标题栏 + 内容区 + 空态
- 浮窗：标题栏（拖拽区）、模式菜单、关闭
- 菜单：⋯ 下拉，点外部关闭
- 提示：窗口尺寸、模式、操作提示

## 6. 背景

**已实现**：

1. **默认极光**：品牌色 + 成功/警告色的低透明度径向渐变，缓慢漂移。
2. **自定义静态图片**：在「自定义背景」里选图，存 IndexedDB（上限 60MB），铺满页面。
3. **自定义视频**：同入口，`<video muted loop autoplay playsinline>` 铺满；大文件由上限拦截。
4. 背景上盖一层 `--dsw-alias-bg-base` 56% 的遮罩，保证文字在深色/浅色主题下都可读；选择后会记住，重启仍在。

**规划**：

- **Wallpaper Engine 联动**（插眼，暂不做）：需要读取本机 Wallpaper Engine 的工程/视频文件，属于系统级访问，插件侧只能读文件，不能控制壁纸进程；且跨平台差异大。等自定义背景稳定后再评估。

背景层不拦截指针事件；`prefers-reduced-motion` 下极光动画停止。

## 7. 无障碍

- 所有可点元素是原生 `button`，有 `aria-label` / `aria-pressed`。
- 焦点可见（不用 `outline: none` 关掉全局焦点环，只对容器关）。
- 对比度：文字只用主题 token，不叠加在纯图像上；背景层加 60% 暗化。
- 动效可关；窗口可键盘关闭（Esc，焦点在窗内时）。
